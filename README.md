# xboom by will.i.am landing page (prototype)

A static site: `index.html`, `styles.css`, `script.js` and `assets/`. No build step.

## Publish with GitHub Pages

1. Create a new repository on github.com.
2. Upload everything in this folder (keep the `assets` folder structure), or push it with git.
3. In the repository: **Settings → Pages → Build and deployment**, set **Source** to *Deploy from a branch*,
   pick `main` and `/ (root)`, then **Save**.
4. After a minute the page is live at `https://<your-username>.github.io/<repository-name>/`.

The page carries `noindex, nofollow`, so search engines won't list it.
